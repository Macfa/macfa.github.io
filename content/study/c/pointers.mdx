포인터는 값이 아니라 **주소**를 담는다. 아래는 `int` 하나를 스택에 두고 그 주소를 읽는 최소 예다.

```c
#include <stdio.h>

int main(void) {
  int value = 42;
  int *ptr = &value;

  printf("value=%d addr=%p *ptr=%d\n", value, (void *)ptr, *ptr);
  return 0;
}
```

`&value`는 `value`가 놓인 위치이고, `*ptr`은 그 위치의 내용을 읽는다. MCU 펌웨어에서도 레지스터 맵은 결국 이 주소 모델이다.
